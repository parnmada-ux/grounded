2. ข้อมูลที่เราเก็บ

เราเก็บข้อมูลเฉพาะที่จำเป็นต่อการให้บริการ เท่านั้น

2.1 ข้อมูลที่คุณให้กับเราโดยตรง

  • อีเมล — ใช้ระบุตัวตนของบัญชีคุณ และส่งการสื่อสารที่จำเป็น (ยืนยันบัญชี ใบเสร็จการสมัครสมาชิก อีเมลกู้คืนบัญชี)
  • รหัสผ่าน — เราไม่เก็บรหัสผ่านในรูปแบบที่อ่านได้ ระบบยืนยันตัวตนใช้บริการของ Google ชื่อ Firebase Authentication ซึ่งเก็บแค่ค่าที่ผ่านการเข้ารหัสทางเดียว (hash) — เป็นมาตรฐานเดียวกับที่ธนาคารและแอปใหญ่ๆ ใช้ แม้แต่ทีม MindoDay เองก็เห็นรหัสจริงของคุณไม่ได้
  • บันทึกสะท้อนความคิดประจำวัน บันทึก journal และข้อความใดๆ ที่คุณเขียนใน MindoDay — จัดเก็บอย่างเป็นส่วนตัว มีคุณคนเดียวที่เห็น
  • การตั้งค่าโปรไฟล์ — รวมถึงการตั้งค่าใดๆ ที่คุณปรับเปลี่ยนภายในแอป

2.2 ข้อมูลที่เก็บอัตโนมัติเมื่อคุณใช้ MindoDay

  • สถานะการสมัครสมาชิก — แพ็กเกจปัจจุบันของคุณ (ฟรี / Premium / Pro) วันเริ่มต้นทดลองใช้ วันต่ออายุ
  • ข้อมูลทางเทคนิคพื้นฐาน — ประเภท browser ระบบปฏิบัติการ ภาษาที่ใช้ และภูมิภาคโดยประมาณ — ใช้เพื่อให้บริการทำงานได้และช่วยแก้ไขข้อผิดพลาด
  • เหตุการณ์การยืนยันตัวตน — เวลาเข้าสู่ระบบ เวลาออกจากระบบ และวันที่สร้างบัญชี

2.3 ข้อมูลที่เก็บโดย Stripe (ผู้ให้บริการรับชำระเงินของเรา)

หากคุณสมัครแพ็กเกจแบบเสียเงิน Stripe จะเป็นผู้ดำเนินการเรื่องการรับชำระเงิน Stripe จะรับข้อมูลบัตรของคุณโดยตรง — เราไม่เห็นและไม่เก็บหมายเลขบัตรเต็ม รหัส CVV หรือวันหมดอายุของบัตรเต็ม สิ่งที่เราได้รับจาก Stripe คือ:

  • customer ID และ subscription ID ที่เชื่อมโยงบัญชี MindoDay ของคุณกับการสมัครสมาชิกที่ Stripe
  • เลข 4 ตัวสุดท้ายของบัตร และแบรนด์บัตร (เช่น "Visa ลงท้าย 4242")
  • ประเทศที่ออกบัตร
  • สถานะการสมัครสมาชิก (active / past due / cancelled)

นโยบายความเป็นส่วนตัวของ Stripe เองมีผลกับข้อมูลที่ Stripe เก็บ ดูได้ที่ https://stripe.com/privacy

2.4 ข้อมูลที่เราไม่เก็บ

  • เราไม่ใช้ tracker (ตัวติดตาม) ของโฆษณาบุคคลที่สาม
  • เราไม่ใช้ analytics จาก social media login
  • เราไม่เก็บข้อมูลตำแหน่งที่แม่นยำ (GPS)
  • เราไม่เก็บข้อมูลชีวมิติ (ลายนิ้วมือ ใบหน้า)
  • เราไม่อ่านรายชื่อติดต่อ ไมโครโฟน กล้อง หรือ sensor อื่นๆ ในมือถือของคุณ

3. เราใช้ข้อมูลของคุณอย่างไร

เราใช้ข้อมูลของคุณเพื่อวัตถุประสงค์ต่อไปนี้ เท่านั้น:

  1. ให้บริการแก่คุณ — แสดงบัญชี บันทึกสะท้อนความคิด และสถานะการสมัครสมาชิกของคุณ
  2. ยืนยันตัวตนอย่างปลอดภัย — เพื่อให้แน่ใจว่ามีเฉพาะคุณคนเดียวที่เข้าสู่บัญชีได้
  3. ดำเนินการเรื่องการรับชำระเงิน — ผ่าน Stripe
  4. ส่งการสื่อสารที่จำเป็น — ยืนยันบัญชี รีเซ็ตรหัสผ่าน ใบเสร็จการสมัครสมาชิก และแจ้งเตือนเรื่องการเปลี่ยนแปลงนโยบายนี้หรือเงื่อนไขการให้บริการ
  5. ปรับปรุงและแก้ไขข้อผิดพลาดของ MindoDay — แก้บั๊ก ป้องกันการใช้งานในทางที่ผิด และเพิ่มความเสถียร
  6. ปฏิบัติตามภาระหน้าที่ทางกฎหมาย — เช่น เก็บบันทึกการรับชำระเงินตามที่ประมวลรัษฎากรของไทยกำหนด

เราไม่นำบันทึกสะท้อนความคิด journal entries หรือเนื้อหาส่วนตัวใดๆ ของคุณ ไปใช้ฝึก AI ไปใช้ขายโฆษณา หรือแชร์ให้บุคคลที่สามเพื่อการตลาด

4. ข้อมูลของคุณถูกเก็บที่ไหน

MindoDay ใช้บริการจากผู้ให้บริการเหล่านี้ ซึ่งทั้งหมดผ่านมาตรฐานความปลอดภัยข้อมูลระดับสากล:

ผู้ให้บริการเก็บอะไรที่ตั้ง
Google Firebase (Authentication, Firestore, Hosting)ข้อมูลรับรองบัญชี (เข้ารหัส) บันทึกสะท้อนความคิด สถานะการสมัครสมาชิก ข้อมูลแอปGoogle Cloud (สิงคโปร์ asia-southeast1)
Cloudflare Workersโค้ด backend API และการจัดการ webhookCloudflare edge network ทั่วโลก
Stripeข้อมูลการรับชำระเงิน รอบบิลการสมัครสมาชิกโครงสร้างพื้นฐานปลอดภัยของ Stripe (สหรัฐ/EU)
GitHub Pagesไฟล์ web app ของ MindoDay (HTML/CSS/JS) — ไม่เก็บข้อมูล userCDN ของ GitHub
Resendการส่งอีเมลธุรกรรม (ยืนยันบัญชี ใบเสร็จ)โครงสร้างพื้นฐานปลอดภัยของ Resend (สหรัฐ)

การใช้ MindoDay หมายความว่าคุณรับทราบว่าข้อมูลของคุณอาจถูกประมวลผลในประเทศนอกไทย รวมถึงสหรัฐอเมริกาและสหภาพยุโรป ซึ่งมีกฎหมายคุ้มครองข้อมูลส่วนบุคคลแตกต่างกัน เราพึ่งพาเงื่อนไขมาตรฐานด้านการคุ้มครองข้อมูลที่ผู้ให้บริการแต่ละรายเสนอ

5. เราเก็บข้อมูลของคุณนานเท่าไหร่

  • ขณะบัญชีของคุณยังใช้งาน: เราเก็บข้อมูลตราบเท่าที่บัญชีของคุณยังมีอยู่
  • หากคุณลบบัญชี: MindoDay มี ระยะผ่อนผัน 30 วัน ข้อมูลของคุณจะถูกทำเครื่องหมายว่ารอลบทันที แต่การลบจริงจะเกิดขึ้นหลัง 30 วัน ในช่วงเวลานี้ คุณสามารถกู้คืนบัญชีได้ด้วยการเข้าสู่ระบบ หลัง 30 วัน ข้อมูลที่ระบุตัวตนได้ทั้งหมดจะถูกลบถาวร รวมถึงบันทึกสะท้อนความคิดและข้อมูลรับรองบัญชี
  • บันทึกการรับชำระเงิน: เก็บ 7 ปี หลังธุรกรรมล่าสุด ตามที่กฎหมายบัญชีและภาษีของไทยกำหนด (ประมวลรัษฎากร มาตรา 87)
  • การสำรองข้อมูล (backup): backup ตามปกติอาจเก็บข้อมูลที่ถูกลบไปแล้วได้นานสุด เพิ่มอีก 35 วัน หลังการลบจริง ก่อนถูกเขียนทับในรอบ backup ปกติ

6. สิทธิของคุณ

คุณมีสิทธิ:

  • เข้าถึงข้อมูล — ขอสำเนาข้อมูลที่เรามีเกี่ยวกับคุณ
  • แก้ไขข้อมูล — ปรับปรุงข้อมูลที่ไม่ถูกต้อง (การตั้งค่าส่วนใหญ่แก้ได้จากในแอป)
  • ลบข้อมูล — ลบบัญชีและบันทึกสะท้อนความคิดถาวร (Settings → Account → Delete Account)
  • จำกัดหรือคัดค้าน — ขอให้เราจำกัดวิธีการใช้ข้อมูลของคุณ
  • ขอความเป็นพกพา (Portability) — ขอบันทึกสะท้อนความคิดของคุณในรูปแบบที่เครื่องอ่านได้ (JSON หรือ PDF)
  • ถอนความยินยอม — สำหรับสิ่งที่เราประมวลผลโดยอาศัยความยินยอมของคุณ (การถอนความยินยอมไม่กระทบการประมวลผลที่ชอบด้วยกฎหมายก่อนถอน)
  • ยื่นเรื่องร้องเรียน — ต่อ คณะกรรมการคุ้มครองข้อมูลส่วนบุคคลของประเทศไทย (PDPC) หรือหน่วยงานคุ้มครองข้อมูลในประเทศของคุณ

เพื่อใช้สิทธิเหล่านี้ ส่งอีเมลมาที่ privacy@mindoday.com เราจะตอบกลับภายใน 30 วัน

หากคุณอยู่ในสหภาพยุโรป (EU), EEA หรือสหราชอาณาจักร (UK) คุณมีสิทธิเพิ่มเติมตาม GDPR / UK GDPR ฐานทางกฎหมายในการประมวลผลของเราคือ (ก) การปฏิบัติตามสัญญา (ให้บริการที่คุณสมัคร) (ข) ผลประโยชน์โดยชอบด้วยกฎหมาย (การแก้บั๊ก ป้องกันการฉ้อโกง) และ (ค) ความยินยอม (เมื่อเกี่ยวข้อง)

8. ความปลอดภัย

เราใช้มาตรการความปลอดภัยมาตรฐานอุตสาหกรรมเพื่อปกป้องข้อมูลของคุณ:

  • การเข้ารหัสระหว่างส่ง — การสื่อสารระหว่างอุปกรณ์ของคุณกับ MindoDay ทั้งหมดใช้ HTTPS (TLS 1.2 ขึ้นไป)
  • การเข้ารหัสขณะจัดเก็บ — ข้อมูลที่เก็บใน Firebase และ Stripe ถูกเข้ารหัสด้วยมาตรฐาน AES-256 (ระดับเดียวกับที่หน่วยงานความมั่นคงและธนาคารใช้)
  • การจัดเก็บรหัสผ่านอย่างปลอดภัย — รหัสผ่านของคุณถูกแปลงเป็นรหัสที่กลับไปเป็นข้อความจริงไม่ได้ก่อนเก็บลงระบบ (ใช้เทคนิคชื่อ bcrypt หรือ PBKDF2 ผ่านบริการ Firebase Authentication ของ Google) — เป็นมาตรฐานความปลอดภัยที่แอปและบริการออนไลน์ทั่วโลกใช้กัน
  • การควบคุมการเข้าถึง — มีเฉพาะบริการ backend ที่ได้รับอนุญาตเท่านั้นที่อ่านบันทึกสะท้อนความคิดของ user ได้ และไม่มี dashboard ภายในที่แสดงเนื้อหาบันทึกสะท้อนความคิดของแต่ละ user

ไม่มีระบบใดที่ปลอดภัย 100% หากเกิดเหตุการณ์ข้อมูลรั่วไหลที่กระทบต่อคุณ เราจะแจ้งให้คุณทราบภายใน 72 ชั่วโมงหลังทราบเหตุ ตามที่ PDPA และ GDPR กำหนด หากจะรายงานข้อกังวลด้านความปลอดภัยหรือช่องโหว่ กรุณาส่งอีเมลมาที่ security@mindoday.com

9. คุกกี้และเทคโนโลยีคล้ายกัน

MindoDay ใช้ cookies และ local storage จำนวนน้อยที่จำเป็นต่อการให้บริการ เท่านั้น:

  • Authentication tokens — เพื่อให้คุณยังคงเข้าสู่ระบบอยู่
  • สถานะแอปในเครื่อง — เพื่อจดจำการตั้งค่าและไม่ต้องดึงข้อมูลใหม่ทุกครั้งที่เปิดหน้า
